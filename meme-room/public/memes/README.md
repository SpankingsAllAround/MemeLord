# Put your meme pictures here

Add your own family-friendly image files directly inside this folder:

- `surprised-cat.jpg`
- `dog-at-the-office.png`
- `what-is-happening.webp`

Supported: `.jpg`, `.jpeg`, `.png`, `.webp` (case-insensitive). Filenames can contain spaces, though lowercase names with hyphens are easier to manage.

**No need to edit `server.js` or any JSON.** The server automatically builds the image deck from the files in this folder when it starts. If at least one valid photo is present, the game uses **only your image deck**; otherwise it keeps the original 16 illustrated emoji prompts as a backup.

To add, change, or remove memes on Render: upload, replace, or delete the files here in your GitHub repository, then commit the changes. Render should redeploy if auto-deploy is on. The new deck becomes available after the deployment finishes. Do not redeploy while a game is active: scores are stored in memory and will reset.

For 25 phones, aim for images about 1200–1600 pixels wide and under 1 MB each when practical. Images will fit the TV and phone screens without being cropped.

Don't put copyrighted images here unless you have permission or a suitable right to use them. Avoid photos of people who have not agreed to be shown at the event, especially children.
